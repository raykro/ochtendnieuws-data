# Ochtendnieuws data

Dagelijkse nieuwsbriefing voor de Ochtendnieuws-app (alleen openbare headlines). Wordt elke ochtend automatisch bijgewerkt.

- `data/index.json`: nieuwste datum en de laatste 14 dagen
- `data/radar.json`: agenda en net-binnen-berichten
- `data/YYYY-MM-DD.json`: de briefing van die dag
